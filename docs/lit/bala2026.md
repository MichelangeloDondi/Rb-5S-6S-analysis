# bala2026

## The system

Theoretical framework (Toruń group, Julienne-Ciuryło lineage) for the isotope dependence of collisional widths and shifts, built from reduced mass, C6 coefficients, and scattering length, applied to a mercury clock transition perturbed by cold rubidium atoms.

## Validity

In the thermal-impact regime, the 85Rb/87Rb reduced-mass difference is about 1%, predicting a negligible isotope effect on collisional width. The mercury-rubidium ultracold system is a different regime from a heated rubidium vapor cell, so only the framework, not the numeric coefficients, applies here.

## Use in this record

Supports the expectation that beta_85 = beta_87, consistent with the measured null result for the isotope dependence of the collisional width.
