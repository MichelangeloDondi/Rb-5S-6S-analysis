# chanu2020

Held. Verified against the PDF, five pages, on 2026-09-10.

## The measurement

The zero crossing of the dynamic differential scalar polarizability of the
S1/2 to D5/2 clock transition in 138Ba+ is determined to be
**459.1614(28) THz**, six parts in a million.

The abstract's own claim for it is that, with previously determined matrix
elements and branching ratios, it "tightly constrains the dynamic differential
scalar polarizability of the clock transition over a large wavelength range",
and that in particular it allows an estimate of the blackbody radiation shift
at room temperature.

## The shape of the argument, which is the transferable part

One measured zero crossing plus existing matrix elements pins a whole
`Delta_alpha(omega)` curve, and the curve then delivers a systematic that
matters to a clock. That is a better return than a single coefficient, and it
is the structure a 5S to 6S magic-wavelength proposal would have to match.

**The co-author list is worth reading.** M. S. Safronova appears on it, and
this record's own static polarizabilities come from Safronova and Safronova
2011. So the theory side of this measurement and the theory side of this
record are the same lineage, which means agreement between them is not an
independent check. That is the same common-mode caution this record already
recorded against an external reading in September.
