# xin2021

Held. Verified against the PDF on 2026-09-11.

## The result

The abstract states, verbatim, that "a sudden change of harmonic oscillator's frequency projects a ground state into a squeezed state" which can
circumvent the time constraint a quantum speed limit imposes on driven
squeezing.

## Why it is held

The trap frequency is a knob the group operates on microsecond timescales. In
this record's language that same knob is the guided light shift, so a group
able to jump it deliberately is a group able to modulate a systematic. That
is a lever this record has not priced and does not claim.
