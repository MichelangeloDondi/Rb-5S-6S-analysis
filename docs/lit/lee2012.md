# lee2012

VERIFIED. Received 18 Apr 2012, Opt. Express 20(13), 14419.

## The system

A control field that switches the Cs 6S-8S two-photon transition between inhibition and enhancement, from the same Tainan group (Tsai/Chui, NCKU) responsible for the intensity-and-density Voigt decomposition of Lee 2010 (Opt. Commun.).

## Use in this record

Lee 2010 is the comparison-table reference, scanning the same two axes (intensity and density) as this analysis. This paper documents the same group's control-field extension of that line and completes the citation trail for the cluster.
