# lee2012

**Held 2026-07-29** (front matter read; received 18 Apr 2012, Opt. Express
**20**(13), 14419). The Tainan group's follow-up line of work to Lee 2010
(Opt. Commun., the intensity-and-density Voigt decomposition the external
audit placed in the comparison table): a control field switching the Cs 6S–8S
two-photon transition between inhibition and enhancement.

Context entry for the sister-line cluster. The comparison-table role stays
with Lee 2010, which scans the same two axes this programme does; this paper
documents the same group's control-field extension and is held mainly so the
