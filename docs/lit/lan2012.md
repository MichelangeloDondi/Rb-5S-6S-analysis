# lan2012

Held. Verified against the PDF on 2026-09-11.

## What it is

A light-pulse atom interferometer in which, verbatim, "we use a tip-tilt mirror
to remove the influence of the Coriolis force from Earth's rotation and to
characterize configuration space wave packets".

## The habit, which is the transferable part

This record's method with a systematic is to carry it in the model and
propagate it. This paper's method is to build a mirror that removes it. Both
are legitimate and they are complementary: a term nulled in hardware needs
no envelope, and a term modelled needs no hardware. A collaboration would
want to say which terms go which way.
