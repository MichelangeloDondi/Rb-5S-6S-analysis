# narsimhan1967

Held, four pages, read in full against the PDF on 2026-09-14.

## What it covers

A vapour-pressure equation for pure liquids in reduced variables. From the
Clapeyron equation and a reference state for the latent heat at 0 K the
author derives -ln Pr = beta chi(Tr), with chi(Tr) a universal function
tabulated on an IBM 1620 for 0.50 < Tr < 0.99 (abstract p. 230. Table 1
p. 231) and beta a substance constant fixed by one data point.

## The claims, with pages

1. The domain: 0.50 < Tr < 0.99 (abstract. Table 1 p. 231).
2. The test set is organic liquids (methane, ethylene, butadiene, carbon
   tetrachloride, methanol among them, Table 2 p. 232), with an average
   error of about 1.9 per cent and a maximum of 3.20 per cent (abstract. P. 231. Table 2), the three statements of the average differing in the
   second decimal as the verify flag records.
3. The equation has not been tested below the normal boiling point
   (p. 231).

## Validity

Within its domain the paper's own tests are the evidence. Outside it
there is none, and the paper says so.

## What this record takes from it

Nothing. Rubidium's critical temperature is about 2093 K and its normal
boiling point 961 K (CRC values, not from this paper), so the archive's
70 to 130 C is Tr = 0.16 to 0.19 and 560 to 620 K below the boiling
point, outside the equation's tested range on both of its own conditions,
and a monatomic metal vapour at 1e-6 atm is not the fluid class the
reduced function was built on. The record's density ladder should not
cite this paper, and the reason is written down here so that it is not re-derived
once rather than rediscovered.
