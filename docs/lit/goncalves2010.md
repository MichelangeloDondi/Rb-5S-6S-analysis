# goncalves2010

VERIFIED for the sections named in the verify_flags (6 of 14 pages). Not physics. See routing.

## What it does

Bianca Soares de Oliveira Gonçalves (Universidade Federal de Goiás) and Marcel Andreotti Musetti
(Universidade de São Paulo), Chapter 4 of "Quality Management and Six Sigma" (ed. A. Coskun,
Sciyo, 2010), pp. 53-66. The chapter proposes a step-by-step process (PMSIC) for choosing which
Six Sigma improvement projects an organization should run, built on a strategic-planning cascade
(Fig. 2, p. 55): Mission -> Strategy -> Performance goals and measures -> Actions. Candidate
projects are filtered through successive priority matrices against named Critical Success Factors
(step 9, p. 64: "This matrix is a tool to link the project to the company's strategic
objectives"), selected and implemented (steps 10-12), and finally checked against the goals that
licensed them (step 13, p. 64: "this phase will monitor the project performance and project
selection processes, that is, whether the organization's goals and objectives have been achieved
through the results of the projects"). Conclusion (p. 65): "the alignment between Six
Sigma projects and the strategy can be achieved through a systematized alignment process."

## Use in this record

Not a physics reference. It is held here only as a possible outside analogue for this
repository's own governance apparatus, which already borrows Six-Sigma/TQM vocabulary (kaizen per
wave, a c-chart discipline for recurring defects, a standing TQM/enforcement report). The
chapter's core mechanism, that a work item is required to trace to a named strategic objective before
it is undertaken and is checked back against that objective afterward, parallels this
repository's own practice of gating work against a standing, explicitly stated aim, but that
parallel is offered here only as a possible point of comparison, not as an established source for
any mechanism in this repository.
