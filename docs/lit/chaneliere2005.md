# chaneliere2005

Held. Verified against the PDF on 2026-09-11.

## What it is

The abstract opens, verbatim, "An elementary quantum network operation involves storing a qubit state in an atomic quantum memory node", and the paper realises the transport of
that state to a remote node as a single photon.

## The line to the fibre work

The technique is electromagnetically induced transparency storage in an atomic
ensemble. `leong2020storage` performs it inside a hollow-core photonic
crystal fibre and reaches over fifty milliseconds. The group's fibre
programme is this programme moved into a waveguide, which is the single
most useful sentence for understanding what they will find interesting.
