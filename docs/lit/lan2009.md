# lan2009

Held. Verified against the PDF on 2026-09-11.

## What it is

The abstract opens, verbatim, "A quantum repeater is a system for long-distance quantum communication that employs quantum memory elements" to mitigate optical fibre transmission
losses, and reports a multiplexed memory in cold rubidium.

## The line to the fibre work

The same ensemble technique appears fifteen years later inside a hollow-core
fibre as `leong2020storage`. The group's fibre programme is this programme
moved into a waveguide.
