# History: what moved, and what it is now

**The question.** Did a number in this record change, and what is it now?
**Takes.** Nothing. Every entry here is dated and closed.
**Gives.** The lineage of every quantity that has moved, with the file
holding the value that is live today.
**Skip if.** You want the current numbers. They are in
[RESULTS.md](RESULTS.md) and the CSVs it names, and every other page in this
repository states only what is live.

> **Unfamiliar with the vocabulary?** [GLOSSARY.md](GLOSSARY.md)
> explains the measurement in six sentences, then defines every term
> and symbol used anywhere in this repository.

## How to use this file

Start at the index below, which is keyed by quantity. A reader looking up
one number does not need to read an entry.

An entry carries four facts: the quantity, what it was, what it is now with
the file that holds the live value, and the cause. The reasoning behind a
correction lives on the page that carries the live statement, and where a
correction produced a general rule, the entry names the rule instead of
teaching it again.

**History is confined here, and every other document states only what is
live.** A page needing to refer to a replaced value links here instead of
repeating the number. That rule exists because a wrong value in a working
document is indistinguishable from a live one to a reader who has just
arrived: on 2026-08-15 a replaced beam waist standing in three
forward-looking documents outvoted the one page that was right, and
produced a wrong edit to the front page. The version-control history
remains the complete record and this file is the curated part.
